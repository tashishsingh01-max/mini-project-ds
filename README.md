# Mini Project (DS)

This is a simple BCA 3rd Year Streamlit project called **Ankur Mini Project**.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

The app starts with deterministic demo market data, so it works offline. Turn on
**Live Data (yfinance)** in the sidebar to try a Yahoo Finance ticker. If the
network request fails, the app automatically returns to demo data.

## Included features

- Chat-style AI Assistant page with a local educational response
- Weekly, Monthly, Yearly, and Custom Duration chart filters
- Demo/live data toggle with safe fallback
- About Project page with college and student information
- Downloadable project ZIP generated by the app
